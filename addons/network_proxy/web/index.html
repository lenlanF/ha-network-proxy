02 / LOCAL NETWORK

局域网共享代理

连接 OpenClash、电脑或其他设备提供的代理。

HTTP 上游不承载 UDP。需要 UDP 流量时请使用支持 UDP 的订阅节点或 SOCKS5 上游。

两种来源可以同时保存，当前只使用选中的来源。

流量范围与代理模式

应用

按容器 IPv4 来源接入 TCP / UDP；host-network 应用无法单独隔离。

集成实例

需连接配套集成。仅代理带 HA 配置条目上下文的 aiohttp 请求；其他客户端与丢失上下文的请求不在此范围。可通过捕获计数核验。

管理入口、局域网和私有地址保留直连。

分享给局域网设备

订阅和共享上游两种来源都可以分享；关闭时仅本机可连接。认证只用于此出口，与 OpenClash 上游认证分开。

其他设备手动设置 HTTP 或 SOCKS5 代理，端口 7890。

局域网自动发现

扫描私有 IPv4 网段（最多 256 个地址），验证常见代理端口，包括 OpenClash 7893。

按需扫描，可能需要约 40 秒。认证代理需填写凭据。
