# Network Proxy

为 Home Assistant OS 提供 Mihomo 代理出口。支持节点订阅、局域网 HTTP/SOCKS5 共享代理、网段发现、节点切换和域名/IP 分流。

通过 HA Ingress 管理页面设置，不需要安装辅助集成即可使用应用。辅助集成可提供实体、自动化及实验性按集成接入功能。

当前为 0.3.2 开发预览。amd64/aarch64 镜像由 GitHub Actions 构建并测试，HA 直接下载预构建镜像。0.3.1 已在 HA OS 验证启动、Ingress 和局域网发现；0.3.2 的连接诊断仍需实机验证。应用提供出口；HA Core 的流量接入需要显式代理配置或客户端适配。

出口测试失败时点击“诊断连接”。诊断检查已保存的 HTTP 上游认证及两个固定 HTTPS 目标，区分 HTTP 407、超时、DNS、拒绝连接和证书错误，不显示密码或原始错误内容。握手成功只证明建立代理隧道；HTTPS 测试成功只证明该目标通过出口可达，不代表所有站点或 HA 集成都已接入。
