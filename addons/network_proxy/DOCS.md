# 使用说明

## 安装与启动

在 HA 应用商店添加仓库 `https://github.com/lenlanF/ha-network-proxy`，刷新后安装 Network Proxy。应用使用 GitHub Actions 发布的 GHCR 镜像，HA 不执行源码构建。需要 HA 能访问 GitHub 和 GHCR。也可将整个 `network_proxy` 目录复制到 HA 的 `/addons/network_proxy`，刷新本地应用后安装，同样拉取预构建镜像。

在应用配置中填写至少 16 字符的随机 `controller_secret`，保存并启动；按需启用开机启动及侧边栏入口。点击“打开 Web 界面”，通过 HA Ingress 管理代理。Ingress 页面不需要再输入控制密钥。

初始没有代理源时默认拒绝出口流量。界面添加源后热加载，配置保存在 `/data/sources.json`。此后 Web 界面保存的配置优先于应用初始代理源参数。

## 代理源与发现

订阅地址使用 Clash/Mihomo YAML 节点订阅。内核每小时自动更新，也可点击“更新订阅”。不提供订阅格式转换器。

局域网共享代理填写 IP/主机名、端口和 HTTP/SOCKS5 协议。需要认证时同时填写用户名密码。已有密码不会回传浏览器；留空可保留，修改代理地址、端口、协议或用户名时需要重新填写，或选择清除认证。

“局域网发现”扫描自己的 RFC1918 IPv4 网段，最多 256 个地址，探测 7890、7891、7893、1080、8080。7893 支持尚未发布的开发源码；0.3.2 使用该端口时请手动填写。HTTP CONNECT 成功或返回代理认证要求、免认证 SOCKS5 协商成功，才会显示候选。选择结果后确认凭据并保存。不支持后台 mDNS；认证 SOCKS5 和非标准端口请手动填写。

使用 OpenClash 时，以其“运行状态”页面显示的代理入口为准。原始订阅端口可能被覆写；检查监听入口及内核日志，不要仅凭 CONNECT 成功判断 HTTPS 可用。若日志报告策略组配置加载失败，应先恢复上游内核运行，再进行出口测试。

不要将此应用自身的代理出口设置为共享上游。应用会阻止明显的 localhost 自循环；使用 HA 的 LAN 地址时，也应避免把 HA 自己的 7890 端口选作上游。

## 节点与分流

在概览页选择出口节点，也可以逐个测速。测速和出口测试使用 HTTPS 请求；当前测试只说明代理出口的连通性，不证明 HA Core 已使用代理，也不检测公网出口 IP。

本地私有 IPv4/IPv6 地址优先直连；其后依次匹配直连域名/IP、代理域名/IP，最后使用“未匹配的连接”设置。域名规则匹配该域名及子域名；每行一个域名或 CIDR。每组最多 128 条规则。CIDR 规则使用 `no-resolve`，不主动为域名请求解析 IP 以匹配该规则。

这些规则仅影响经过此出口的请求。应用不自动更改 HA Core 网络路由，不提供宿主 TUN 透明代理。

## 辅助集成

将 `custom_components/network_proxy` 复制到 `/config/custom_components/network_proxy` 并重启 HA，添加 Network Proxy 集成。

本地安装可使用内部地址：

- 控制 API：`http://local-network-proxy:9090`
- 管理 API：`http://local-network-proxy:9091`
- HTTP 代理出口：`http://local-network-proxy:7890`

仓库安装的内部名称包含仓库标识，需要相应修改主机名。控制和管理端口默认不映射到宿主 LAN，集成通过 HA 内部网络通信。

集成提供节点实体、版本/捕获计数传感器和订阅刷新按钮。配置中可以选择已有的集成实例，实验性代理默认关闭，只覆盖带 HA 配置条目任务上下文的 aiohttp 请求。它不覆盖 HTTPX、requests、原始套接字及无上下文请求；不能承诺任意集成全部流量接入。

## 端口与认证

7890 是 HTTP/SOCKS mixed 出口，可在应用网络设置中关闭宿主映射。只供 HA Core 使用时，可关闭 LAN 映射并使用内部地址。需要 LAN 客户端时建议设置 `proxy_username` 和 `proxy_password`。辅助集成中填写相同的出口认证信息。

9090/9091 默认仅内部使用；如人为暴露，仅开放给可信网络，并使用控制密钥。8099 是 Ingress 界面端口，不应映射到 LAN；服务仅接受 Supervisor Ingress 地址 `172.30.32.2` 的连接。

运行记录仅显示本次运行中的管理操作，最多 100 条；Mihomo 原始运行日志请在 HA 应用日志页面查看。

## 验证与卸载

保存源后确认节点出现；选择节点并测试出口。重启应用后确认源与规则仍存在。辅助集成启用实验路由后观察捕获计数，不能用勾选状态判断是否覆盖全部流量。

停用实验路由或卸载辅助集成会恢复它安装的请求钩子。应用从未修改主机路由；停止应用会使依赖其出口的请求失败，需要在使用代理的客户端中停用代理配置。

## 上游

代理内核：Mihomo v1.19.12，使用官方镜像的未修改二进制。上游源码和许可证见 [第三方说明](THIRD_PARTY.md)。源码包不包含内核二进制；预构建运行镜像包含内核、许可证及对应源码链接。
